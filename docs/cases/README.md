# Case studies

Three programs and the Rust py2rs writes for them (generated by `make.py`):

- [linked_list.md](linked_list.md): a linked stack; moves, `take()`, references and
  `Result` inferred without annotations
- [inventory.md](inventory.md): dataclasses, `defaultdict`, sorting and formatting;
  `&[T]` / `&mut Vec<T>` parameters
- [graph.md](graph.md): objects that point at each other, with `@shared`
